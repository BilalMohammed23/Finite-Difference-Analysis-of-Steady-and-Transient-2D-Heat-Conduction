# Finite-Difference-Analysis-of-Steady-and-Transient-2D-Heat-Conduction
Developed MATLAB finite-difference solvers for steady and transient 2D heat conduction, implementing Jacobi, Gauss-Seidel, SOR with both explicit and implicit formulations to study convergence behavior, stability limits, computational efficiency, and temperature-field evolution across different numerical formulations.
